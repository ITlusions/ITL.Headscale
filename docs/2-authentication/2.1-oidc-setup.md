# 2.1 OIDC setup

## The client

`values.yaml`'s `keycloak` block (`clientId: headscale`) declares a `KeycloakOIDCClient` CR against the `itlusions` realm, separate from `ITL.Headscale.UI`'s `headplane` client - see [1.1](../1-architecture/1.1-overview.md#two-keycloak-clients-not-one) for why.

Headscale's own `oidc` config block controls who's actually let in once they authenticate:

```yaml
oidc:
  issuer: https://keycloak.itlusions.com/realms/itlusions
  clientId: headscale
  clientSecretRef:
    name: headscale-oidc-secret
    key: client-secret
  allowedGroups:
    - /vpn-users
```

`allowedGroups` must exactly string-match the `groups` claim value Keycloak issues - including the leading slash. This is the single most common way this breaks; see [2.2](2.2-keycloak-claims-gotchas.md) for the exact failure and fix.

## The login flow

```bash
tailscale up --login-server=https://headscale.itlusions.com
```

opens a browser, redirects through Keycloak, and on success the device registers. No static key, no manual peer-list editing - group membership in `/vpn-users` is the only gate.

## Verifying a real token's claims without guessing

Browser/session caching makes it easy to think a fix didn't work when it actually did (or vice versa). The reliable way to see exactly what claims Keycloak would issue for a real user+client combo, bypassing all of that:

```bash
kcadm.sh get clients/<headscale-client-id>/evaluate-scopes/generate-example-id-token?userId=<user-id>&scope=openid
```

This returns the actual token payload Keycloak would produce. Used twice during the 2026-10-24 incident (see [2.2](2.2-keycloak-claims-gotchas.md)) to pin down the exact claim-format mismatch, rather than guessing from symptoms.

## Minimal ACL policy note

Headscale will log `"Failed to read the ACL policy for groups"` if no ACL policy exists at all - this is a warning, not an error, and the default behavior with no policy is allow-all between registered devices. See [3.2](../3-network/3.2-acl-policy.md) for the actual policy now in place.
